## API reference

The API reference is made from the code, and published with each release:

- Rust: [docs.rs/colliery-io-aurora](https://docs.rs/colliery-io-aurora)

## Pages

- [Tokens](tokens/): each token, with its light, dark and hyper value.
- [Components](components/): each component, with its props.
- [Themes](themes/): the themes, `data-theme`, the storage key and the theme
  functions.
- [Cargo features and stylesheets](features/): the features of the crate,
  and the constants and functions that give the CSS.
- [Rules and checks](checks/): the tests that keep the colours right.
